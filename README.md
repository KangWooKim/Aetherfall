# Aetherfall

Unreal Engine C++로 만든 개인 액션 게임 프로젝트입니다. 약공격 연계·가드·패리·처형·검기 전투와, 조우 진행·체크포인트 재도전·메뉴·설정을 구현합니다. 현재 구현을 다른 게임 프로그래머가 읽을 수 있도록 코드와 기술 설명을 함께 제공합니다.

## 구현에서 살펴볼 부분

- 전투 컴포넌트가 실행 상태를 소유하고 행동 허용·타이머 정리·자원 계산을 보조 구조로 분리합니다. 피해 적용처럼 상태를 바꾸는 함수의 경계도 설명합니다.
- 진행 라벨과 플레이어 스냅샷으로 저장·재도전을 연결합니다. 플레이어 복원 중 저장 요청은 반환하며 별도 대기열에 남기지 않습니다.
- 월드별 검기 풀은 반환한 액터를 재사용합니다. 보관 상한과 전체 생성 수를 구분합니다.
- 설정 확인 기한은 플랫폼 시간과 CoreTicker를 사용하며, 연출 서비스는 상태·입력 잠금·종료 이벤트를 관리합니다.

## 자료와 구현의 범위

공개 저장소는 소스 검토용이며 완성된 실행 패키지나 전체 콘텐츠 배포본이 아닙니다. 이 저장소만으로 Unreal 프로젝트를 열거나 패키징할 수 없습니다. 원본의 .uproject, Config, Content와 해당 에셋 권한·참조 구성이 필요합니다.

기술 설명은 현재 소스를 기준으로 작성합니다. 기존 GIF는 기능 시연이며 정량 성능 결과가 아닙니다. [실행 성능](Docs/03_Technical/CoreTechnologies.md#9-실행-성능의-현재-범위)에서 현재 소스의 60 FPS 제한 전투 관측 3회와 실제 부하·경고·미측정 범위를 안내합니다. 과거 실행 사본의 자료는 별도 문서에 보존합니다. 기본 TTS는 모의 서비스이며 실제 컷신 재생과 콘텐츠 연결은 별도로 확인해야 합니다.

Codex의 도움을 받아 소스 코드를 작성하고 검증한 개인 프로젝트입니다.

외부 에셋의 제작자·사용권과 프로젝트 코드의 작성 범위는 구분합니다. 공개된 소스만으로 모델·애니메이션·음원 등의 재배포 권한이 제공되지는 않습니다.
